# Konstantinos Morfis — Personal Portfolio

A personal portfolio website presenting my background, technical skills, interests, and selected software projects. Built with **HTML and CSS only**, as a web development capstone project.

## Features

- Hero section with a brief introduction and links to my work.
- Résumé section covering education, experience, skills, and languages.
- Selected projects with descriptions, technology tags, and GitHub links.
- About section with personal interests.
- Contact section linking to my GitHub profile.
- Responsive layouts using CSS Grid, Flexbox, and media queries.
- Smooth anchor navigation and a fixed back-to-top button.
- Accessibility features including semantic HTML, a skip link, visible keyboard focus, and reduced-motion support.
- Decorative illustrations created with HTML and CSS, without external image assets.

## Technologies

- HTML5
- CSS3

No JavaScript, frameworks, package installation, or build step is required.

## Run Locally

1. Download and extract the repository, or clone it using Git.
2. Keep `index.html` and `style.css` in the same folder.
3. Open `index.html` in a web browser.

Alternatively, open the project folder in VS Code and use a local preview extension such as Live Server.

## Customization

- Edit `index.html` to update the introduction, résumé, projects, and contact links.
- Edit the variables in `:root` in `style.css` to change the color palette.
- Adjust the media queries in `style.css` to refine the layout for different screen sizes.
